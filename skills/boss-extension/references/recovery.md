# 异常与安全停止

- 找不到 BOSS 标签或没登录：核对当前 Chrome Profile，不猜账号。
- Refresh 无 List：核对求职期望索引、自然响应和下载回执，不连续盲刷新。
- Scroll 无新批次：确认是否到末端，不高速重复滚动。
- Detail 无响应或职位 ID 不一致：记录失败项并停止，不直接发独立详情请求。
- Hook/Worker 丢失或下载 UNKNOWN：查看只读诊断和已有文件，未确认副作用前禁止重试。
- Greet 没有明确成功：报告 UNKNOWN，**不重复发送真实招聘消息**。
- 验证码、安全校验、限流：停止，不规避平台控制。

用户明确要求新一轮完整采集时可在前一任务安全终态使用 fresh=1；只能重置本轮判定缓存，不能删除历史原始 JSON、SQLite 或成功沟通记录。
