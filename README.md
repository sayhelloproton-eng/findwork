## Findwork 是什么？

**让 AI 帮你找到更合适的岗位，把有限的时间和投递机会用在更值得争取的工作上。**

找工作时，招聘平台每天展示大量岗位，而个人精力以及每天可使用的沟通、投递机会有限。Findwork 基于用户自己的招聘平台账号及岗位期望，遵循平台原有的使用方式，帮助用户从岗位初筛到 AI 二次评估、再到授权沟通和结果记录，提高求职效率。

## 它如何工作？

1. **岗位期望初筛**：利用用户已设置的岗位期望，获取对应岗位列表和职位详情。
2. **入库与去重**：统一保存岗位及原始信息，以已有岗位记录为主，避免重复评估和重复沟通。
3. **AI 二次评估**：结合**个人画像、求职偏好、排除条件**，评估哪些岗位值得争取、哪些不考虑、哪些需要补充信息。
4. **优先使用投递机会**：对值得沟通的岗位结合真实证据确定优先顺序，经用户确认后使用原有平台的沟通或投递功能。
5. **岗位工作台与统计**：在本地查看岗位、评估结果、实际沟通记录和求职效率数据。

**目标不是投得越多越好，而是让有限的投递机会更有价值。**

## 产品边界

- 岗位管理、AI 筛选、投递决策和真实动作结果属于 Findwork；投递后的聊天、招聘跟进和面试流程属于原有招聘平台。
- 用户拥有个人资料与岗位数据；数据库与三项私人策略仅存本机，且不包含在公开仓库中。
- 当前已有一个招聘平台的采集与授权沟通能力；其他平台可以后续接入同一工作台，不能将“可扩展”理解为“全部平台已经实现”。
- 沟通与正式提交简历是不同动作。只有真实回执才可记录成功，AI 不会仅凭匹配结果擅自发送消息。
